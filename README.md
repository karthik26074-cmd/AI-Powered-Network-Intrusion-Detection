# AI-Powered-Network-Intrusion-Detection
Built an end-to-end NIDS classifying traffic into 12 classes (benign + 11 attacks). Soft-voting ensemble on 2.8M+ CIC-IDS flows hit 99.8% accuracy, 93% macro F1. Flask/SQLite app with auth, live dashboard (~40 ms latency), threat simulator, and AI assistant for threat explanations.
